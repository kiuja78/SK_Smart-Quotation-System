설치 및 업데이트
GitHub Pages 저장소의 기존 index.html과 assets 폴더를 ZIP 안 파일로 모두 교체하세요.
브라우저에서 Ctrl+Shift+R(강력 새로고침)을 실행하세요.
기존 관리자 데이터는 동일 브라우저 로컬 저장 구조를 유지합니다. 업데이트 전 설정/백업에서 내보내기를 권장합니다.

주의
가격과 상품 데이터는 원본 SK 계산기 연동 구조를 유지합니다. 독립된 데이터 복제나 쿠쿠 데이터로의 저장은 하지 않습니다.
UI 검증은 샘플 데이터 기반이며 실제 모든 모델의 사진/요금은 공개 계산기 연동 상태에 따라 달라질 수 있습니다.
