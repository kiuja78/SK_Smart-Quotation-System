기본적으로 계산기의 원본 이미지를 사용합니다.

운영 방식 안내

이 V1.5은 GitHub Pages에서 실행할 수 있는 관리자 웹용입니다. 요금·사진은 원본 계산기 데이터와 연동됩니다. 관리자가 견적에서 직접 수정한 금액, 담당자 등록정보, 이력, 별도 업로드 이미지는 브라우저 저장이므로 PC 간 공유를 위해서는 추후 별도 SK 전용 Google Apps Script/시트 연동이 필요합니다. 기존 쿠쿠 API/구글시트에는 절대 저장하지 않습니다.
